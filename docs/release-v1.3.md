# v1.3 开发版验证记录

范围：单组或 N 组同任务实验；可见配置与差异、不可变版本快照、组 worktree／目录、
确定性队列／端口、MCP 工具／事件、比较证据。基于 `feat/multi-config-experiments`，
不迁移旧业务会话，不覆盖 workflow-v1.2.0，不自动发布。

已验证（本地合成数据，零模型调用）：

- 新增 Python 28 项：配置校验、完整自然语言解析、修订冲突、冻结幂等性、不同组代码隔离、
  内容篡改拒绝、历史固定规则限制、3 组／2 槽位、全局容量、失败保留、未知用量不冒充核实、
  不重复启动、不阻塞 UI 的状态写入、停止的未确认子代、指令去重、冻结中断恢复。
- 临时真实服务：占用端口后重新分配、3 个并发配方、进程身份校验、死租约回收、HTTP 鉴权、
  跨站／Host 拒绝。外部占用者不被结束。
- 精确父会话下的合成原生子代日志：父边、重复 message ID、外来会话拒绝；不读取其他项目。
- MCP stdio 真实进程：握手、工具调用、本机插件生成；事件签名挑战使用注入式合成接收器，
  验证去重和最多三次投递。不是云端端到端验证。
- Playwright + 本机 Chrome：表单、3 组选择／复制／移除、自然语言修改、冻结排队／取消／复制；
  1280、768、360 宽度无横向溢出，无页面脚本异常。
- 既有 Python 63 项回归：31 观测、21 遥测入口、11 lane 状态；既有 Node notify 回归通过。
  JS／zsh／Python 语法检查及 Git diff whitespace 检查通过。

未验证：真实 Herdr JSON／可见输入的跨版本兼容、新模型账号权限、真实 Claude 多组业务
完整运行、实际递归深度／并发环境变量效果、全量 token／账单覆盖、Dot 安装与云端唤醒。
当前派发器只允许从真实 Herdr shell 接入；无法在本 Codex shell 假造 pane 完成这些验证。
后续实跑应先用小合成任务，核对 run/session、实际模型与加载哈希，再扩展业务任务。

剩余边界：配置完整性不是 OS 沙箱；应用须使用提供的数据／服务配方，硬编码共享数据库
不会自动隔离。只有主管中断不证明全部子代停止；相关记录保留待核对并占用槽位。
质量不自动评分，未观察到的 effort／子代／费用仍为未知；复盘者按用户授权分析。
